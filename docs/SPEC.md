# APEX 언어 명세 (초안)

## 렉싱
- 주석: `//` 줄, `/* */` 중첩 가능
- 정수: `123`, `1_000`; 문자열 이스케이프: `\n \t \" \\`
- 키워드: fn struct enum trait impl theorem let match by own mut unsafe `_`
- 기호: `( ) { } [ ] , ; : := -> => & + - * / = == . < > |`

## 타입과 곱셈수 (QTT)
인자는 곱셈수 `0 | 1 | ω`를 가진다.
- `0`: 컴파일 타임에만 존재, 소거된다 (타입, 증명)
- `1` (`own`): 정확히 한 번 사용(이동)
- `ω`: 자유롭게 복사 (`Copy` 타입 기본값)

## 소유권
- 이동 후 사용은 오류. `Drop`은 스코프 종료 시 삽입.
- `&T` 공유 빌림, `&mut T` 배타적 빌림. 검사는 MIR 단계(NLL).
- 타입에 나타난 값의 사용은 곱셈수 0이므로 이동으로 간주하지 않는다.

## 예시
```apex
theorem add_comm (a b: Nat) : a + b = b + a := by
    induction a <;> simp [*]
```
